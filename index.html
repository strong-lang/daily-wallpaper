收到壁纸后怎么设

发给朋友时可以把这段一起发过去。

  1. Windows 电脑：下载图片 → 右键图片 →「设为桌面背景」。
  2. Mac：下载图片 → 右键图片 →「设定桌面图片」。
  3. 安卓手机：打开图片 → 菜单 →「设为壁纸」，主屏幕和锁屏都能设。
  4. iPhone：打开图片 → 分享 →「用作墙纸」。
